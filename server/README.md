# PrimeClass Server

## Stack

- Node.js
- TypeScript
- Fastify
- MySQL

## Quick Start

1. Copy `.env.example` to `.env`
2. Adjust MySQL connection values
3. Run `npm install`
4. Run `SEED_ADMIN_PASSWORD='set-a-local-admin-password' SEED_APP_PASSWORD='set-a-local-demo-password' npm run db:bootstrap`
5. Run `npm run dev`

Local helper commands after `.env` is configured:

- `npm run db:bootstrap`
- `npm run smoke`

## Database

Schema:

- `../docs/schema.mysql.sql`

Seed:

- `./sql/seed.mysql.sql`

Seeded admin account:

- username: `admin`
- password: provided via `SEED_ADMIN_PASSWORD` or generated by `npm run db:bootstrap`

Seeded app demo account:

- username: `student_demo`
- password: provided via `SEED_APP_PASSWORD` or generated by `npm run db:bootstrap`

## Notes

- Seed data includes basic dictionaries: `subject`, `grade`, `term`, `version`.
- `npm run db:bootstrap` prints the seeded account credentials after import. Re-running it may rotate generated passwords unless you provide explicit `SEED_*` values.
- Seed data stores course/profile taxonomy fields with dictionary codes, not display names.
- Local storage uses the `root_path` field in `storage_configs`; relative paths are resolved from the `server/` working directory.
- `public_base_url` is optional for all storage providers. If configured, uploaded assets will return a direct `public_url`.
- Recommended storage config fields:
  - `local`: `root_path`, optional `public_base_url`, `prefix`
  - `s3`: `bucket`, `region`, `access_key`, `secret_key`, optional `endpoint`, `force_path_style`, `public_base_url`, `prefix`
  - `tencent_cos`: `bucket`, `region`, `secret_id`, `secret_key`, optional `public_base_url`, `prefix`
  - `ftp`: `host`, `port`, `username`, `password`, `root_path`, optional `secure`, `public_base_url`, `prefix`
- In the current sandbox environment, compile/build verification is available, but binding to a real port may be blocked.
