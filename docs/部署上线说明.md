# 优学课堂部署上线说明

本文档针对当前统一后的项目结构：

- 前端：`app-web`，Next.js 16，包含学员端和后台管理端
- 后端：`server`，Fastify + MySQL

## 一、目录结构

```text
<project-root>
├── app-web
├── server
├── deploy
└── docs
```

## 二、服务端口规划

- `server` API：`3000`
- `app-web` Web：`3001`
- 外部访问统一由 Nginx 转发到 80/443

推荐访问路径：

- 学员端首页：`https://your-domain.com/`
- 后台管理端：`https://your-domain.com/admin`
- API：`https://your-domain.com/api/v1/...`

## 三、上线前准备

### 1. MySQL

当前项目已使用 MySQL，正式环境需要准备可用数据库，并导入：

- 表结构：`docs/schema.mysql.sql`
- 初始化数据：`server/sql/seed.mysql.sql`

### 2. Node.js

建议 Node.js 版本：

- `>= 20`

### 3. PM2

建议用 PM2 托管两个 Node 进程：

- API 服务
- Next.js Web 服务

## 四、后端部署

### 1. 环境变量

复制：

```bash
cd server
cp .env.production.example .env
```

至少修改：

- `MYSQL_HOST`
- `MYSQL_PORT`
- `MYSQL_DATABASE`
- `MYSQL_USER`
- `MYSQL_PASSWORD`
- `JWT_SECRET`
- `CORS_ORIGIN`

### 2. 安装与构建

```bash
cd server
npm install
npm run build
```

## 五、前端部署

### 1. 环境变量

复制：

```bash
cd app-web
cp .env.production.example .env.production
```

修改：

- `NEXT_PUBLIC_API_BASE_URL=https://your-domain.com/api/v1/app`
- `NEXT_PUBLIC_ADMIN_API_BASE_URL=https://your-domain.com/api/v1/admin`

### 2. 安装与构建

```bash
cd app-web
npm install
npm run build
```

前端已启用 `standalone` 构建，但当前 PM2 示例仍使用 `next start`，这样最直观，也便于直接运维。

## 六、PM2 启动

根目录已提供：

- `deploy/ecosystem.config.cjs`

启动命令：

```bash
cd <project-root>
pm2 start deploy/ecosystem.config.cjs
pm2 save
pm2 startup
```

常用命令：

```bash
pm2 list
pm2 logs primeclass-api
pm2 logs primeclass-web
pm2 restart primeclass-api
pm2 restart primeclass-web
```

## 七、Nginx 配置

示例文件：

- `deploy/nginx.primeclass.conf.example`

核心逻辑：

- `/api/` 转发到 `127.0.0.1:3000`
- 其他路径转发到 `127.0.0.1:3001`

部署时建议再补：

- HTTPS 证书
- `listen 443 ssl`
- 80 跳转 443

## 八、上线顺序

建议顺序：

1. 配置 MySQL
2. 导入表结构和种子数据
3. 配置后端 `.env`
4. 构建并启动后端
5. 配置前端 `.env.production`
6. 构建并启动前端
7. 配置 Nginx
8. 验证域名访问

## 九、上线检查清单

- `https://your-domain.com/` 可以打开学员端首页
- `https://your-domain.com/admin` 可以打开后台登录页
- 自定义管理员账号可登录
- 已初始化的学员演示账号可登录
- `/api/v1/app/home` 可正常返回
- `/api/v1/admin/auth/login` 可正常返回
- 激活码兑换流程可用
- 后台课程、用户、会员、系统设置页面均可打开

## 十、补充说明

- 当前前后台前端已经统一到 `app-web`
- 旧的 `admin-web` 已移除
- 如需对象存储上线，需要在后台系统设置中补齐 `local / s3 / tencent_cos / ftp` 的正式配置
