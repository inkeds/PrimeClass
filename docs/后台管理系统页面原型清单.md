# 优学课堂后台管理系统页面原型清单

## 1. 文档信息

- 文档版本：v0.1
- 更新时间：2026-03-23
- 关联文档：`docs/项目设计规范.md`
- 文档目标：输出后台管理系统首版需要设计和实现的页面清单、页面结构、关键字段和交互要求，作为后台原型设计与前端管理端开发的直接依据

## 2. 原型范围

首版后台原型范围仅覆盖以下模块：

- 后台登录
- 工作台
- 用户管理
- 课程管理
- 会员管理
- 系统设置

首版不纳入本次原型的页面：

- 第三方支付配置
- 订单管理
- 退款管理
- 多租户管理
- 复杂审批流

## 3. 后台整体设计原则

### 3.1 视觉与布局原则

- 使用标准后台布局：左侧导航 + 顶部操作区 + 内容区。
- 列表页优先采用“筛选区 + 表格 + 分页”的结构。
- 编辑页优先采用“基础信息 + 业务配置 + 资源关联 + 保存区”的结构。
- 高风险操作必须使用二次确认弹窗。

### 3.2 页面模板约束

首版后台主要使用以下 6 类模板：

| 模板类型 | 说明 | 典型页面 |
| --- | --- | --- |
| 登录页 | 单页认证 | 后台登录 |
| 工作台页 | 数据概览与快捷入口 | 工作台 |
| 列表页 | 筛选 + 表格 + 分页 | 用户列表、课程列表、激活码列表 |
| 详情页 | 概览 + 分区信息 | 用户详情 |
| 编辑页 | 表单 + 资源选择 + 操作栏 | 课程编辑、套餐编辑、系统设置 |
| 配置页 | 表单分组 + 测试按钮 | 存储设置、上传设置 |

### 3.3 全局交互组件

后台原型必须统一以下全局组件：

- 顶部全局搜索
- 面包屑
- 表格批量操作栏
- 抽屉表单
- 二次确认弹窗
- 上传弹窗
- 状态标签
- 操作结果通知

## 5. 页面详细设计

### 5.1 A-01 后台登录

#### 页面目标

- 管理员登录后台。
- 承接权限入口和安全校验。

#### 页面结构

1. 品牌区：Logo、系统名称、副标题。
2. 登录区：账号、密码、验证码。
3. 操作区：登录按钮、错误提示。

#### 必备字段

- 管理员账号
- 登录密码
- 图形验证码

#### 关键交互

- 连续输错密码时强化验证码校验。
- 登录失败需要明确展示失败原因。
- 登录成功跳转工作台。

#### 原型状态

- 默认态
- 输入态
- 登录中
- 登录失败

### 5.2 A-02 工作台

#### 页面目标

- 给管理员提供系统总览与待处理事项。

#### 页面模块

1. 数据卡片
2. 待处理事项
3. 快捷入口
4. 系统公告或注意事项

#### 数据卡片建议

- 总用户数
- 今日活跃用户
- 总课程数
- 已发布课程数
- 有效会员数
- 今日激活码兑换数

#### 快捷入口建议

- 新增课程
- 生成激活码批次
- 查看兑换记录
- 存储配置检测

### 5.3 U-01 用户列表

#### 页面目标

- 支持运营按条件快速找到用户并查看状态。

#### 页面结构

1. 筛选区
2. 批量操作栏
3. 用户表格
4. 分页区

#### 筛选条件

- 用户 ID
- 昵称
- 手机号/登录账号
- 会员状态
- 账号状态
- 注册时间
- 最近活跃时间

#### 表格字段

| 字段 | 说明 |
| --- | --- |
| 用户 ID | 主键展示 |
| 头像 | 缩略图 |
| 昵称 | 用户昵称 |
| 手机号/账号 | 登录标识 |
| 会员状态 | 普通/VIP/永久/过期 |
| 学习课程数 | 已学习课程数 |
| 最近活跃时间 | 最后活跃时间 |
| 账号状态 | 正常/冻结/注销 |
| 操作 | 查看详情、冻结/解冻 |

#### 原型重点

- 会员状态需彩色标签展示。
- 冻结操作需要二次确认。
- 支持导出当前筛选结果。

### 5.4 U-02 用户详情

#### 页面目标

- 集中查看用户基本信息、学习信息和会员信息。

#### 页面结构

1. 用户头部卡片
2. Tab 区域
3. 操作栏

#### Tab 建议

- 基本信息
- 学习概览
- 会员记录
- 操作日志

#### 头部卡片字段

- 头像
- 昵称
- 用户 ID
- 手机号/账号
- 会员状态
- 注册时间
- 最近登录时间

#### 操作区

- 冻结/解冻账号
- 新增客服备注
- 查看兑换记录
- 发起人工补偿

### 5.5 U-03 用户学习记录

#### 页面目标

#### 页面结构

1. 顶部用户摘要
2. 筛选区
3. 学习记录表格

#### 表格字段

- 课程名称

- 课时名称
- 最近学习时间
- 学习进度

### 5.6 C-01 课程列表

#### 页面目标

- 管理同步课和专题课的全量课程。

#### 页面结构

1. 筛选区
2. 操作区
3. 课程表格
4. 分页区

#### 筛选条件

- 课程类型
- 学科
- 年级
- 学期
- 教材版本
- 权限类型
- 课程状态
- 标题关键字

#### 操作按钮

- 新增课程
- 批量上架
- 批量下架
- 导出课程

#### 表格字段

| 字段 | 说明 |
| --- | --- |
| 封面 | 缩略图 |
| 课程 ID | 唯一编号 |
| 标题 | 课程标题 |
| 类型 | 同步课/专题课 |
| 学科 | 学科 |
| 年级版本 | 年级 + 版本 |
| 权限 | FREE/VIP |
| 状态 | 草稿/已发布/已下架 |
| 更新时间 | 最近编辑时间 |
| 操作 | 编辑、章节管理、上下架、删除 |

### 5.7 C-02 新增/编辑课程

#### 页面目标

- 创建或修改课程基础信息与展示信息。

#### 页面结构

1. 基础信息区
2. 展示信息区
3. 权限与状态区
4. 资源关联区
5. 保存区

#### 基础信息字段

- 课程类型
- 课程标题
- 学科
- 年级
- 学期
- 教材版本
- 专题标签
- 讲师名称

#### 展示信息字段

- 课程简介
- 封面图
- 推荐语
- 排序值

#### 权限字段

- 是否 FREE
- 是否 VIP
- 状态

#### 原型规则

- 同步课显示教材版本字段，专题课显示专题标签字段。
- 封面图必须支持资源库选择和直接上传两种方式。
- 保存区固定在页面底部或侧边。

### 5.8 C-03 章节管理

#### 页面目标

- 配置课程下的章节和课时结构。

#### 页面结构

1. 课程摘要
2. 章节树/列表
3. 课时编辑区
4. 资源绑定区

#### 课时字段

- 课时标题
- 排序
- 视频资源
- 讲义资源
- 是否试看
- 时长
- 状态

#### 关键交互

- 支持拖拽排序或上下移动排序。
- 支持新增章、节、课时。
- 删除课时需要确认且提示影响。

### 5.9 C-04 专题标签管理

#### 页面目标

- 管理专题课的分类标签。

#### 页面结构

1. 标签筛选区
2. 标签列表
3. 新增/编辑抽屉

#### 字段建议

- 标签名称
- 所属学科
- 排序
- 状态
- 备注

### 5.10 C-05 资源管理

#### 页面目标

- 查看和管理所有上传资源。

#### 页面结构

1. 筛选区
2. 上传按钮
3. 资源列表/表格
4. 资源详情抽屉

#### 筛选项

- 资源类型
- 存储驱动
- 上传时间
- 文件名
- 所属业务

#### 表格字段

- 资源 ID
- 文件名
- 类型
- 大小
- 存储驱动
- 访问地址
- 上传时间
- 操作

#### 操作建议

- 预览
- 复制地址
- 重新上传
- 删除资源

### 5.11 M-01 会员套餐列表

#### 页面目标

- 管理会员套餐定义。

#### 页面结构

1. 套餐列表
2. 状态筛选
3. 新增按钮

#### 表格字段

- 套餐名称
- 套餐类型
- 时长/权益
- 状态
- 创建时间
- 操作

### 5.12 M-02 新增/编辑会员套餐

#### 页面目标

- 配置激活码所对应的会员权益。

#### 字段建议

- 套餐名称
- 套餐类型
- 有效时长
- 是否永久
- 权益说明
- 状态

#### 规则

- 永久卡启用后应屏蔽普通时长字段。
- 套餐停用后不可用于新批次生成。

### 5.13 M-03 激活码批次列表

#### 页面目标

- 管理激活码批次的生成和发放。

#### 表格字段

- 批次号
- 套餐名称
- 生成数量
- 已使用数量
- 已过期数量
- 创建人
- 创建时间
- 状态
- 操作

#### 操作

- 查看批次详情
- 导出批次激活码
- 作废批次

### 5.14 M-04 新建激活码批次

#### 页面目标

- 生成一批可投放的激活码。

#### 字段建议

- 选择会员套餐
- 生成数量
- 有效截止时间
- 渠道来源
- 备注

#### 原型规则

- 生成前需要提示数量和安全风险。
- 生成成功后展示批次号和导出入口。

- 状态

#### 表格字段

- 失效时间

- 操作

### 5.16 M-06 兑换记录

#### 页面目标

- 查看用户兑换明细和结果。

#### 表格字段

#### 页面目标

- 客服为特定用户做会员补偿。

#### 字段建议

- 用户 ID
- 补偿类型
- 增加天数
- 是否永久
- 原因说明

#### 风险控制

- 必须二次确认。
- 必须填写补偿原因。
- 成功后写入操作日志。

#### 页面目标

- 维护系统基础信息。

#### 页面字段

- 系统名称
- H5 标题
- Logo
- 默认头像
- 客服联系方式
- 用户协议地址

- 版权信息

### 5.19 S-02 展示设置

#### 页面目标

- 维护前端展示类配置。

#### 页面字段

- 首页 Banner 文案
- VIP 标签文案
- 兑换弹窗文案
- 默认空状态文案
- 客服入口文案

### 5.20 S-03 存储设置

#### 页面目标

- 统一配置 4 类存储驱动。

#### 页面结构

1. 默认驱动选择
2. 4 个驱动配置卡片
3. 连接测试区
4. 保存区

#### 本页必须支持的驱动

- 本地存储
- S3 存储桶
- 腾讯云对象存储
- FTP 存储

#### 每个驱动的必要交互

- 启用/停用
- 配置编辑
- 连接测试
- 设为默认

#### 安全要求

- 密钥类字段默认脱敏显示。
- 修改密钥时必须重新输入完整值。

### 5.21 S-04 上传设置

#### 页面目标

#### 字段建议

- 视频大小上限

#### 字段建议

- 字典类型

- 备注

## 6. 通用状态与异常页面

后台原型必须补齐以下状态：

- 空列表状态
- 无权限状态
- 上传失败状态
- 保存失败状态
- 连接测试失败状态
- 数据加载中状态
