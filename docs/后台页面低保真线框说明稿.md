## 3. 后台统一线框规范

### 3.1 画板建议

- 桌面端基准：`1440 x 1024`
- 内容区最小宽度：`1200`
- 左侧导航宽度建议：`220 - 240`
- 顶部栏高度建议：`56 - 64`
- 页面内容左右内边距建议：`24`

### 3.2 页面骨架

后台统一采用以下骨架：

```text
+--------------------------------------------------------------------------------------------------+
| Top Bar: Logo / 全局搜索 / 消息 / 管理员                                                        |
+----------------------+---------------------------------------------------------------------------+
| Left Nav             | Breadcrumb / 标题 / 页面级操作                                            |
|                      +---------------------------------------------------------------------------+
| 菜单树               | Main Content Area                                                         |
|                      |                                                                           |
|                      | 筛选区 / 数据卡 / 表单 / 表格 / 详情卡 / 抽屉                            |
|                      |                                                                           |
+----------------------+---------------------------------------------------------------------------+
```

### 3.3 模板规则

| 页面类型 | 必备模块 |
| --- | --- |
| 列表页 | 页面标题、筛选区、操作区、表格区、分页区 |
| 详情页 | 摘要卡、Tab、详情区、操作区 |
| 编辑页 | 标题、表单分区、资源关联区、保存操作区 |
| 配置页 | 分组卡片、测试按钮、保存区 |

### 3.4 标注规范

- 低保真图只表达结构，不表达品牌细节和装饰。
- 占位图统一写为 `Image` / `Logo` / `Avatar`。
- 表格列不必逐像素对齐，但要表达主次关系。
- 危险操作在说明中标出“二次确认”。
